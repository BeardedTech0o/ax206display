First time here?

The first start wrote a random password to initial-password.txt in the data directory (/var/lib/ax206display for the packaged service). Read it on the Pi with sudo cat /var/lib/ax206display/initial-password.txt. Forgot a password you set? Run sudo ax206display-passwd.
